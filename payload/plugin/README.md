# ANODHAS Voice 0.2.0 для DeepSeek Harness

Локальный голосовой диалог с перебиванием и обычная диктовка одним плагином.

**Этот выпуск: Mac с Apple Silicon, macOS 26+, DeepSeek Harness 0.2.2-rc.1.** Windows, Intel и более старые версии macOS не поддерживаются этим архивом. На других версиях Harness 0.2.x требуется проверка совместимости.

## Установка на другом Mac

1. Установите DeepSeek Harness в `/Applications` и подключите свою модель/подписку. Плагин не содержит чужих подписок, аккаунтов или ключей.
2. Распакуйте архив и запустите **Подготовить.command**. Нужен Интернет для однократной установки моделей и среды. Установщик проверит SHA-256, использует существующий файл Parakeet v3 Q4_K_M в Handy, если размер и SHA-256 совпадают, либо загрузит одну копию модели; подготовит 6 локальных голосов и отдельную Python-среду (официальный Astral Python Build Standalone). `sudo` не нужен.
3. По завершении установщик покажет постоянную папку плагина и готовое поручение для Harness. В новом чате Harness вставьте это поручение: штатный `plugin_manager` должен выполнить `install_bundle` с этой папкой как `target`. Нужное подтверждение установки выполняет сам пользователь в Harness.
4. После активации появятся фиолетовая кнопка разговора и обычный микрофон диктовки. Если старое окно не обновилось — штатно переоткройте чат. Разрешите Harness доступ к микрофону при первом использовании.

CLI не используется для изменения Desktop-профиля: этой композицией управляет сам Electron Harness. **Два шага обязательны:** подготовка, затем установка bundle через Harness. Установка сырой папки `plugin` из архива до подготовки не готова к работе.

Установленные файлы находятся в `~/Library/Application Support/ANODHAS/HarnessVoice/0.2.0`. Это постоянная рабочая папка — не удаляйте её, пока плагин установлен. Исходный скачанный архив после успешной установки можно убрать.

## Использование

- Фиолетовая кнопка: разговор с моделью текущего чата. Начало вашей речи прерывает озвучивание.
- Обычный микрофон: запись → остановка → редактируемый текст в поле ввода. Отправка отдельно.
- Шестерёнка: голос, громкость, скорость 0.7–2× и режим «На всех рабочих столах».
- Крестик выключает голос, сохраняя работу чата; квадрат отдельно останавливает задачу.

Это локальная цепочка ASR → выбранная модель Harness → TTS, с репликами по паузам. Распознавание Parakeet не является нативным потоковым speech-to-speech. Для ответа требуется работающая собственная модель Harness; аудио распознаётся и озвучивается локально, распознанный текст отправляется выбранной модели чата.

## Хранение и приватность

История аудио не сохраняется. Во время обработки могут существовать временные PCM/TXT/WAV; они удаляются после использования. Подтверждённые собственные остатки завершившегося процесса очищаются при следующем запуске. Чужие и активные папки не удаляются. После аварии до следующего запуска временные остатки возможны. История текста — обычная история Harness, плагин её не очищает.

Веса моделей хранятся постоянно в одном model-store либо используются из Handy по ссылке, не копируются на каждый чат. Подготовка на чистом Mac загружает около 550 МиБ моделей и 154 МиБ установочных wheel-файлов и около 24 МиБ Python runtime; установленная среда занимает больше места. pip-кэш отключён. Переписки, SSH, Telegram и личные настройки автора в архив не включены. Endpoint/порт и случайный секрет создаются на целевом Mac. **Передавать другому человеку нужно исходный архив, а не уже подготовленную папку с локальной конфигурацией.**

## Голоса и лицензии

В переносимом выпуске 6 русских тембров Silero CIS, лицензия MIT. Parakeet GGUF — CC-BY-4.0 с атрибуцией NVIDIA/Handy. Веса не вложены в архив и загружаются из официальных источников с проверкой размера и SHA-256. Не включены некоммерческие Silero v5_6_ru и скопированные звуки Codex. Сигналы включения/кнопок в этом пакете — собственные синтезированные звуки.

## Ограничения и удаление

- Сборка ad-hoc подписана, Apple Developer ID/notarization отсутствуют. Публичная публикация в маркетплейсе не выполнялась.
- Плагин заменяет только optional-композицию стандартной диктовки своей копией штатных UI/API с общим распознавателем. Модели LLM/подписки не меняет.
- Не устанавливайте одновременно с прежней ручной сборкой ANODHAS Voice: сначала требуется её миграция. На компьютере автора она не заменялась.
- Для удаления сначала удалите bundle штатным менеджером Harness. Затем можно удалить его версионную папку. Модели Handy не удаляйте; общий model-store удаляется отдельно только если больше не нужен.
- Если подготовка прервалась, повторите её. Lock после сбоя удаляйте только убедившись, что прежняя подготовка завершилась.

Проверки и точный предел приёмки приведены в VERIFY.md. Физический новый Mac не заменяется тестом изолированного профиля.
