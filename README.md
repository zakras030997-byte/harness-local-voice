# ANODHAS Voice для DeepSeek Harness

Локальный голосовой разговор с перебиванием, диктовка и голоса по аудиообразцу. Графический установщик подключает всё без команд и промптов.

## Установка

Скачайте [ANODHAS Voice 0.3.1 — DMG](https://github.com/zakras030997-byte/harness-local-voice/releases/download/v0.3.1/ANODHAS-Voice-Installer-0.3.1-arm64.dmg), откройте образ и запустите **«Установить ANODHAS Voice»**. Нажмите **«Установить»**, дождитесь подготовки и откройте Harness. Устанавливать Python, Homebrew или вводить команды не нужно.

Требуются **Apple Silicon, macOS 26+, DeepSeek Harness 0.2.2-rc.1** в `/Applications`. Harness должен быть один раз запущен и первоначально настроен. На других версиях совместимость отдельно не подтверждена. При необходимости установщик предложит штатно закрыть Harness. При первом использовании разрешите доступ к микрофону.

Сборка ad-hoc подписана, **без Apple Developer ID и нотарификации**. macOS может запросить пользовательское разрешение на запуск; установщик не отключает Gatekeeper. На физическом другом Mac первый запуск ещё требует приёмки.

Первоначальная подготовка требует интернета: примерно 3 ГБ загрузок, включая Qwen (2.34 ГБ), распознавание, Python и зависимости; установленная среда занимает больше места. Модели скачиваются с официальных источников по закреплённым версиям и проверяются SHA-256. Совместимая модель Parakeet Handy используется повторно. Существующие LLM, подписки, Handy и рабочие проекты не заменяются.

## Возможности

- Разговор в выбранном чате, перебивание и обычная диктовка в редактируемый черновик.
- Шесть русских голосов Silero CIS, громкость и скорость речи.
- **Голосовые эталоны:** шестерёнка → «Добавить голосовой эталон» → название и образец WAV/MP3/M4A/AIFF длительностью 3–30 секунд, до 12 МиБ → выбрать голос → «Послушать». До 20 эталонов. Если текст образца не указан, его распознает общая модель Handy. Используйте свой голос или образец, на использование которого у вас есть разрешение.
- Локальный Qwen3-TTS Base 1.7B, MLX, 4-bit. Создание речи по эталону медленнее обычных голосов; качество и сходство зависят от образца.
- Стеклянная янтарно-фиолетовая сфера с дымкой, волной от микрофона/озвучивания и чёткими круглыми кнопками. Прозрачный виджет, опционально на всех рабочих столах; reduced motion поддержан.
- **Четыре ползунка:** размер виджета 60–160%, чувствительность микрофона 0.5–3×, громкость и скорость. Сфера с кнопками масштабируется целиком, меню остаётся читаемым. Значения сохраняются после перезапуска. При1× чувствительность прежняя; повышение усиливает и фоновый шум. Настройка чувствительности относится к потоковому разговору.
- Отдельные действия: заглушить микрофон, выключить озвучивание, закончить голосовой режим с продолжением задачи, остановить саму задачу.

## Хранение и обновление

Речь распознаётся и озвучивается локально. Это цепочка ASR → выбранная модель Harness → TTS: распознанный текст отправляется модели чата и сохраняется обычной историей Harness. Отдельная история аудио не ведётся; временные файлы удаляются после обработки. Qwen загружается по требованию и его процесс завершается после синтеза/отмены.

Эталоны сохраняются намеренно в `~/Library/Application Support/ANODHAS/HarnessVoice/reference-voices`; это ваша библиотека голосов, не кэш разговоров. Они остаются при обновлении, как и выбор голоса, скорость и громкость. Не удаляйте библиотеку, если хотите сохранить эталоны.

Установщик обновляет собственную предыдущую публичную установку с резервной копией профиля и проверкой остальных настроек. При неизвестном конфликтующем пакете или прежней ручной сборке он останавливается для отдельной миграции. Не удаляйте старые папки до успешной проверки новой версии. Удаление — штатным менеджером плагинов Harness; общие модели Handy сохраняйте.

## Сборка и проверка

`installer/` содержит AppKit-установщик и подключение к Desktop CLI Harness; `payload/` — плагин и проверяемые манифесты моделей/зависимостей. Получателю компилятор не нужен. На Mac с Command Line Tools и SDK macOS 26.5:

```sh
python3 installer/build.py
```

Скрипт собирает native-сферу и установщик, подписывает собственные bundles ad-hoc. Выход: `build/release/Установить ANODHAS Voice.app`. DMG и SHA-256 доступны в [релизе](https://github.com/zakras030997-byte/harness-local-voice/releases/tag/v0.3.1).

Проверяются автоматическая подготовка в изолированной папке, ASR, stock TTS и реальный Qwen-синтез, штатная регистрация в отдельном Desktop-профиле, обновление предыдущей версии, повторная установка и сохранность других настроек. Проверка на одном Mac не заменяет приёмку микрофона/разрешений на другом физическом устройстве.
