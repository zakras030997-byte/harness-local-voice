# ANODHAS Voice для DeepSeek Harness

Локальный голосовой разговор с перебиванием и обычная диктовка. Графический установщик подключает обе функции без команд и промптов.

## Установка

Скачайте [DMG 0.2.1](dist/ANODHAS-Voice-Installer-0.2.1-arm64.dmg?raw=true), откройте его и запустите **«Установить ANODHAS Voice»**. Нажмите **«Установить»**, дождитесь подготовки и откройте Harness. При необходимости подтвердите штатное закрытие Harness и доступ к микрофону в macOS.

Требуются **Apple Silicon, macOS 26+, DeepSeek Harness 0.2.2-rc.1** в `/Applications`. Harness должен быть один раз запущен и первоначально настроен. На других версиях требуется отдельная проверка. Сборка ad-hoc подписана, без Apple Developer ID и нотарификации; Gatekeeper может потребовать пользовательского разрешения. Защита macOS не отключается.

Первый запуск требует интернета: около 730 МиБ загрузок на чистом Mac. Совместимая модель Parakeet Handy используется повторно. LLM, подписки и Handy не заменяются.

## Что внутри

- Parakeet TDT v3 Q4_K_M для локального распознавания; веса загружаются отдельно с SHA-256 проверкой.
- Шесть русских голосов Silero CIS, громкость, скорость и перебивание.
- Разговор в текущем чате и диктовка в редактируемый черновик.
- Прозрачный голосовой виджет и режим всех рабочих столов.
- Штатное подключение через установленный Desktop CLI Harness, резервная копия профиля и проверка сохранности других настроек.

Речь распознаётся и озвучивается локально. Это цепочка ASR → выбранная модель Harness → TTS; распознанный текст передаётся выбранной модели чата. Отдельной истории аудио нет. Временные файлы удаляются после обработки, подтверждённые остатки аварийного процесса — при следующем запуске. Текст сохраняется обычной историей Harness.

## Исходники и сборка

- `installer/`: нативное окно AppKit, подготовка, подключение и генерация иконки.
- `payload/`: общий голосовой плагин 0.2.0, загрузчик моделей и Python; исходники native-компонентов и инструкции в `payload/plugin/BUILD.md`.
- `dist/`: проверенный установщик 0.2.1 и SHA-256.

Сборка установщика на Mac с совместимыми Xcode Command Line Tools и SDK macOS 26.5:

```sh
python3 installer/build.py
```

Результат: `build/release/Установить ANODHAS Voice.app`. Копирование в DMG выполняется `hdiutil create` с этой папкой. Сборка компилятора и подпись артефакта не заменяют нотарификацию Apple.

## Проверено и ограничения

Подключение в изолированном Desktop-профиле, повторная установка, защита занятого профиля, конфликт прежней ручной сборки и сохранность других настроек проверены. Готовый DMG проверен, подпись приложения из него подтверждена, его окно запущено. ASR и TTS проверялись отдельно в голосовом пакете. Полный первый запуск с живым микрофоном на физическом другом Mac пока требует приёмки.

При обнаружении прежней ручной сборки установщик останавливается: необходима миграция. Удаление — штатным менеджером плагинов Harness, затем можно убрать версионную папку из `~/Library/Application Support/ANODHAS/HarnessVoice`. Не удаляйте общие модели Handy.

## Лицензии

Код ANODHAS предоставлен без публичной лицензии (UNLICENSED). Права третьих сторон сохраняются: [атрибуции и лицензии](payload/plugin/THIRD_PARTY_NOTICES.md). Веса, личные ключи, аккаунты, записи разговоров и подписки в репозитории отсутствуют. Звуки Codex и некоммерческие веса Silero сюда не включены.
