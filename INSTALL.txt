ANODHAS Voice · установщик 0.3.1

1. Установите DeepSeek Harness 0.2.2-rc.1 в «Программы» и один раз завершите начальную настройку.
2. Откройте DMG и запустите «Установить ANODHAS Voice» → «Установить».
3. Дождитесь загрузки моделей и автоматического подключения. Python, Homebrew и команды не нужны.
4. Откройте Harness. Разрешите микрофон при первом использовании.
5. В шестерёнке доступны размер виджета, чувствительность микрофона, громкость и скорость; значения сохраняются.
6. Для своего голоса: шестерёнка → «Добавить голосовой эталон» → образец 3–30 секунд → выбрать голос → «Послушать».

Apple Silicon · macOS 26+. При первой подготовке нужен интернет и место для моделей/среды: загрузки примерно 3 ГБ. Повторно используются совпадающие модели Handy. Настройки и подписки сохраняются, создаётся резервная копия профиля.

Подпись ad-hoc, без Developer ID/notarization: macOS может запросить разрешение на запуск. Защита не отключается. Другие версии Harness и первый запуск на физическом другом Mac отдельно не подтверждены.
